# Clareza Relacional

PROMPT MESTRE — QUIZ INTERATIVO DE ANÁLISE DE COMPORTAMENTOS MASCULINOS

Crie um quiz web premium, altamente envolvente, emocional e otimizado para conversão, voltado para mulheres que desejam compreender melhor determinados comportamentos presentes no relacionamento com o homem ao lado delas.

O projeto deve ser construído como uma experiência de análise e reflexão comportamental, e NÃO como uma ferramenta de diagnóstico psicológico ou clínico.

O objetivo principal é levar a usuária por uma jornada progressiva de identificação → reflexão → aprofundamento → análise → expectativa → desbloqueio do resultado → apresentação do material complementar.

3. POSICIONAMENTO DO QUIZ

Utilize uma comunicação emocional, mas responsável.

Não diga:

"Vamos descobrir se ele é narcisista."

Não faça diagnóstico.

Prefira:

"Vamos analisar os padrões de comportamento que você descreveu."

"Suas respostas podem indicar comportamentos que merecem atenção."

"Esta análise é baseada nos comportamentos relatados por você."

A experiência deve ajudar a usuária a organizar aquilo que ela está vivendo e identificar padrões comportamentais.
